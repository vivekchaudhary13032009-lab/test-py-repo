Block and Inline Elements

In this page I am checking how block and inline tags behave in the layout.

1. Block Elements

Every block element starts on a new line and takes the full width of the page, even if the text inside it is short.

This is a div. It takes the full line.

This is a paragraph. It also takes the full line.

This is a heading. Same thing here.

Another div below it, so it goes to a new line.

2. Inline Elements

Inline elements do not start on a new line. They stay in the same line and take only as much space as their content needs.

My name is Vivek, I study CSE and my favourite subject is C Programming. You can visit Google for more help. All of these boxes are in one single line.

This block has an inline span and a strong text inside it. The block is wide, but the inline parts are small.
